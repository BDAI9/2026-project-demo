# 한끼산책 — 가상 데이터 데모

가게와 주소, 좌표, 가격, 평점 및 모든 속성은 **실제 업체 정보가 아닌 예시**입니다. Python Streamlit 앱은 로컬 Python 서버가 화면을 만들고 브라우저에서 표시합니다. 백엔드 없이 검색, 필터, 찜, 공유 ID를 시연합니다.

## 즉시 확인: HTML 미리보기
`preview/index.html`을 파일 탐색기에서 더블클릭합니다. CSS와 JavaScript가 내장되어 인터넷이나 설치가 필요 없습니다. 브라우저의 로컬 저장소 사용이 허용되어야 찜과 공유 ID가 저장됩니다. 브라우저나 설정에 따라 로컬 파일의 저장소가 제한될 수 있습니다. 공유 ID는 같은 브라우저에만 저장되므로 다른 기기나 사용자에게 공유되지 않습니다. HTML은 Streamlit과 별도로 구현되었으며 데이터, 찜, 공유가 연동되지 않습니다.

## Streamlit 실행: Windows PowerShell
프로젝트 폴더에서 다음을 실행합니다. Python 3.10 이상 권장.
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
PowerShell 활성화가 제한되면 활성화 없이 `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`와 `.\.venv\Scripts\python.exe -m streamlit run app.py`를 실행할 수 있습니다.

## 기능과 한계
- 이름/주소 부분 검색, 식당·카페/바 카테고리, 알레르기·식단, 1인 예시 가격 필터를 지원합니다. 검색 유형은 하나 이상 선택해야 합니다.
- 식당과 카페/바를 모두 선택하면 예산을 해제하고 선택한 거리 이내 직선거리 조합을 표시합니다. 거리와 위치는 예시이며 도보 거리가 아닙니다. 조합 평점은 두 평점의 산술평균입니다.
- 결과는 최대 20개, 평점 내림차순과 이름순입니다. 조건에 맞는 결과가 3개보다 적으면 실제 결과만 보여 줍니다.
- 해산물 알레르기 선택 시 정보가 명시적으로 '없음'인 식당만 포함하며 미확인은 제외합니다. 식단은 선택한 항목을 모두 명시한 식당만 포함합니다. 이 정보는 안전성 보장이 아닙니다.
- Streamlit 찜은 사용자 세션, 공유 ID는 해당 서버 프로세스의 메모리에만 있습니다. 재시작 시 사라지며 여러 서버 간 공유되지 않습니다. 공유는 찜 목록의 생성 시점 복사본입니다. 로그인, 실시간 동기화, 영구 저장, 실제 데이터, 운영 보안은 구현되지 않았습니다.
- HTML 데이터는 Python 데이터의 독립 복사본입니다. 수동 변경 시 양쪽을 함께 갱신해야 합니다.

## 실제 API 연결 (제안이며 팀 협의 필요)
현재 `ui.py`는 `data_access.py`의 `search_places`, `search_pairs`, `create_share`, `get_share`, `PLACES`를 사용합니다. 실제 연결 시 데이터 접근 파일을 API 클라이언트로 교체하고, `PLACES` 직접 접근을 가게 ID 조회 함수로 바꾸며, 오류·시간 초과와 응답 검증을 UI에 연결합니다. 비동기 처리, 재시도와 인증도 운영 정책에 맞춰 추가합니다. `API_BASE_URL`은 환경변수로 설정하고, 인증 비밀은 환경변수 또는 배포 플랫폼의 비밀 저장소에서 읽습니다. 실제 키나 `.env`, `.streamlit/secrets.toml`은 커밋하지 않습니다. 현재 데모는 API_BASE_URL을 읽지 않습니다.

### API 예시
확정 명세가 아닌 협의용 예시입니다. JSON은 UTF-8, 모든 가격은 원, 좌표는 WGS84로 가정합니다.

- `POST /api/v1/search`: `{"query":"예시구","types":["restaurant"],"categories":["한식"],"seafood_free":true,"diets":["비건"],"budget":{"min":0,"max":30000},"limit":20}` → `{"items":[{"id":"place-01","name":"달빛밥상","type":"restaurant","category":"한식","address":"가상 주소","lat":37.5,"lon":127.0,"price":12000,"rating":4.7,"seafood":"없음","diets":["비건"],"wifi":true}],"total":1}`.
- `POST /api/v1/pairs/search`: 위 검색 조건 중 예산을 제외하고 `max_distance_m:100` 추가 → `{"items":[{"restaurant":{"id":"place-01","name":"달빛밥상"},"cafe_bar":{"id":"place-07","name":"모래카페"},"distance_m":99,"rating":4.7}],"total":1}`. 실제 응답에는 두 가게의 전체 필드가 필요합니다.
- `POST /api/v1/shares`: `{"place_ids":["place-01"]}` → `201 {"id":"A1B2C3D","place_ids":["place-01"],"created_at":"2026-01-01T00:00:00Z","expires_at":null}`.
- `GET /api/v1/shares/A1B2C3D` → `200 {"id":"A1B2C3D","places":[{"id":"place-01","name":"달빛밥상"}],"expires_at":null}`. 실제 응답에는 가게 전체 필드가 필요합니다.
- 로그인 기반 찜의 예: `GET /api/v1/favorites` → `{"place_ids":["place-01"]}`; `PUT /api/v1/favorites/place-01` → `204`; `DELETE /api/v1/favorites/place-01` → `204`.
- 오류 공통 예: `400 {"error":{"code":"INVALID_FILTER","message":"예산 범위가 올바르지 않습니다."}}`, `404 {"error":{"code":"SHARE_NOT_FOUND","message":"공유 ID를 찾을 수 없습니다."}}`; 인증 실패 401, 권한 부족 403, 만료 410, 서버 오류 500도 협의합니다.

백엔드는 입력 검증, 필터·정렬·거리 계산과 결과 제한을 담당하고 프론트엔드는 조건 입력과 결과 표시를 담당합니다. 실제 공유에는 영속 DB의 공유 ID, 생성자/접근 정책, 생성·만료 시각, 가게 ID 목록과 충돌 방지, 인증·권한 검사 및 남용 방지가 필요합니다. 찜은 사용자 ID와 가게 ID의 관계로 저장합니다. 정보 미확인은 null이나 별도 상태로 나타내고, 식단과 알레르기에는 출처와 확인 시각을 추가해야 합니다.

운영 전 데이터 출처와 이용 권한, 가격 기준·갱신 주기, 알레르기·식단 정보의 신뢰성과 검증 책임, 거리 기준, 공유 ID의 만료·공개 범위·접근 권한을 팀에서 결정해야 합니다.

## PDF와 가정
PDF는 서비스명·검색·식당/카페/예산, 식당 카테고리 전체와 카페만 기본 선택, 동시 선택 시 예산 비활성화, 거리 옵션, 결과 최대 20개와 최소 3개, 7자리 공유 ID를 제시합니다. 이 구현은 사용자 요청을 우선하여 일치 결과가 3개 미만이면 결과를 생성하지 않고 실제 개수만 보여 줍니다. 실시간 공유 및 ID 주소 이동은 구현하지 않았습니다.
Streamlit, 부분 문자열 검색, 1인 예시 가격, 직선거리, 조합 평균 평점, 검색어가 조합 중 한 곳에 일치하는 방식, 영문 대문자·숫자 7자리 ID, 공유 목록의 복사본은 데모를 위한 가정입니다. 정보가 없는 와이파이는 확인되지 않음, 알레르기는 정보 미확인으로 표시합니다. 식당 식단 필터는 두 유형 조합에서도 식당에만 적용합니다. 빈 검색어는 선택 조건 전체를 검색합니다.

## 점검
1. 식당을 선택해 여섯 카테고리 기본 선택을 확인하고 `달빛`을 검색합니다.
2. 카페/바만 선택해 카페만 선택되어 있는지 확인하고 바를 추가합니다.
3. 예산을 켜서 슬라이더와 숫자의 동기화, 최소가 최대보다 클 때 오류, 범위 내 결과를 확인합니다.
4. 식당과 카페/바를 함께 선택해 예산이 해제되는지, 100m 기본 거리와 각 거리 옵션 및 빈 결과를 확인합니다.
5. 없는 이름을 검색하고 결과 없음 및 세 개 미만 안내를 확인합니다.
6. 결과에서 찜을 누르고 공유 화면에서 ID를 만든 후 조회합니다. 잘못된 형식과 없는 ID를 입력합니다.
